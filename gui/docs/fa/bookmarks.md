# نشانک‌ها

صفحات را از افزونه مرورگر یا با دکمه + در GUI ذخیره کنید و بعداً برای ضبط دانلودها باز کنید.

## نوار کناری

در داشبورد، **نشانک‌ها** زیر فهرست صف‌ها در پنل چپ قرار دارد. آن را انتخاب کنید تا همه صفحات ذخیره‌شده برای نشست daemon متصل را ببینید.

جدول نشانک‌ها شامل این موارد است:

- عنوان صفحه
- نشانی
- تعداد پیوند (تعداد پیوندهایی که افزونه هنگام نشانک‌گذاری در صفحه شمارش کرده)

ردیف‌های فرد و زوج پس‌زمینه متفاوت دارند تا خواندن آسان‌تر شود.

## انتخاب

- روی ردیف یا چک‌باکس آن کلیک کنید تا انتخاب شود.
- **Ctrl+کلیک** (Cmd در macOS) ردیف‌ها را جداگانه اضافه یا حذف می‌کند.
- **Shift+کلیک** محدوده‌ای بین آخرین ردیف لنگر و ردیف کلیک‌شده را انتخاب می‌کند.
- چک‌باکس سرستون همه ردیف‌های قابل‌مشاهده را انتخاب یا لغو می‌کند (با فیلتر جستجوی فعلی).

وقتی یک یا چند نشانک انتخاب شده باشد، نوار ابزار تعداد انتخاب و دکمه **حذف انتخاب‌شده‌ها** را نشان می‌دهد.

## عملیات

| عمل | توضیح |
|-----|--------|
| **افزودن (+)** | دیالوگ افزودن دستی نشانی صفحه |
| **باز کردن صفحه** | نشانی نشانک را در مرورگر پیش‌فرض باز می‌کند |
| **کپی پیوند** | نشانی صفحه را در کلیپ‌بورد کپی می‌کند |
| **حذف** | یک نشانک را از daemon حذف می‌کند |
| **حذف انتخاب‌شده‌ها** | همه نشانک‌های انتخاب‌شده را پس از تأیید حذف می‌کند |
| **جستجو** | جدول را بر اساس عنوان، نشانی یا تعداد پیوند فیلتر می‌کند |
| **ورود** | نشانک‌ها را از فایل JSON به daemon وارد می‌کند |
| **خروج** | فهرست فعلی نشانک‌ها را در فایل JSON روی رایانه شما ذخیره می‌کند |

## افزونه مرورگر

در پنجره افزونه:

- اگر **Put selected links in a separate tab** در تنظیمات افزونه فعال باشد، از زبانه **Bookmark** استفاده کنید.
- اگر این گزینه خاموش باشد، پنل نشانک در پایین فهرست رسانه نمایش داده می‌شود.

این پنل عنوان صفحه، نشانی، تعداد پیوند و دکمه **Bookmark this page** یا **Remove bookmark** را نشان می‌دهد.

## مسیر ذخیره‌سازی

نشانک‌ها در فایل JSON روی ماشین daemon ذخیره می‌شوند (پیش‌فرض: `bookmarks.json` کنار `config.json`). مسیر را در **Settings → Daemon → Bookmarks storage** تغییر دهید.
